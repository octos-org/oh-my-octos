Login behavior

/app, /admin, /learn: click “Continue without a password” (local solo). The admin card also seeds octos_auth_token from the constant below.
/code: this page fetches /api/auth/solo, seeds octoscode-web's tab storage, then Connect is one click; pick a workspace and Add & Start.
/matrix-chat: the page logs in with the local account automatically.

Ops

restart / status / logs

launchctl kickstart -k gui/$(id -u)/local.octos.serve · local.matrix.synapse · local.ngrok
brew services restart caddy · brew services list
logs: ~/.octos/logs/serve.out.log, ~/octos-matrix/synapse.log, ~/.octos/logs/ngrok.out.log

update

octos: npm update -g @octos-org/octos + restart. Frontends: git pull, pnpm install, rebuild with OCTOSCODE_WEB_BASE_PATH=/code/ or BASE_URL=/learn/. This static page reloads without a restart.

troubleshooting

Telegram unreachable = network blocks api.telegram.org. Lark 404 = request URL/ngrok mismatch. Admin locked out = solo login then rotate the 8-char token and update the constant in this file. Ports: lsof -nP -iTCP:8080 -iTCP:50080 -iTCP:8008

Everything listens on loopback. Secrets live in the macOS keychain or 0600 local files; this page references them without embedding API keys.
